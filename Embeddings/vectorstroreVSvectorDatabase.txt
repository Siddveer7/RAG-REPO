1) Vector strore VS Vector database 

    once we convert the chunk into vector we need to store into vector DB , 

    vector store : it is kinda tool where it focuses on storing and searching vectors efficiently 
    vector database : A full Featured database desgined for vector data at scale

    simple similarity search 
    advanced search with filters,Metadata queries and database operations 

    usually runs in memory or a local file, single machine operarion 
    distributed system with replication ,sharding and high availibilty

    prototypes,research, small applications with <1M 
    production Systems,enterprise, enterporise application , billlions of vectors
